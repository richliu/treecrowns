方法與限制

1. 資料來源

  • 衛星影像：Copernicus Sentinel-2 Level-2A 地表反射率（10 m），與 BigGIS 平台建置的 Sentinel-2 影像同源。 BigGIS 的 Sentinel-2 圖磚清單 API 需申請 IP 開通，故本站改由 ESA 開放資料在 AWS 的 Cloud-Optimized GeoTIFF （sentinel-2-l2a-cogs，以 STAC 搜尋）直接讀取。
  • 縣市界：內政部直轄市、縣市界線（經 taiwan-atlas 簡化版）。
  • 方法依據：BigGIS〈Sentinel-2 影像變異分析〉 所述之決策樹分類（Liu et al. 2018；Liu et al. 2019, Sci. Rep. 9:7279）。

2. 年度去雲合成

台灣多雲，單張影像無法涵蓋全島。每個 Sentinel-2 圖幅（MGRS tile）每年挑選雲量最低的 {{ params.max_scenes }} 景， 以 L2A 內附的 SCL 場景分類遮去雲、雲影、卷雲、飽和與無資料像元，並以藍光反射率 > 0.15 排除殘雲薄霧， 對每個像元取各波段中位數，另外計算 NDVI 的年中位數與第 25 百分位。

3. 分類（BigGIS 決策樹 + 延伸）

指標公式用途
NDVI(NIR − Red)/(NIR + Red)Level 1：植生 / 其它
SI 陰影指標(PC1nor − I)(1 + S)/(PC1nor + I + S)Level 2：陰影 / 非陰影（PC1 為 RGB 主成分，I、S 為 HSI 強度與飽和度）
Gn 綠度指標(Green − Red)/(Green + Red)Level 3：低植生 / 裸露地
MNDWI(Green − SWIR1)/(Green + SWIR1)水體（延伸）
與 BigGIS 的差異：BigGIS 文章未公開各指標門檻與 SI 的輸入尺度；實測 SI 公式在 L2A 地表反射率上分母會跨越 0、數值不穩定， 因此陰影改以「非植生且 NIR < {{ params.SHADOW_NIR_MAX }}、可見光平均 < {{ params.SHADOW_VIS_MAX }}」判定。 山區地形陰影中的森林 NDVI 仍高（約 0.85），仍會被計入樹冠，不影響樹冠統計。NDVI 門檻以嘉南平原與中央山脈樣區人工校正。
  • 樹冠：年中位數 NDVI > {{ params.T_NDVI }}，且全年第 25 百分位 NDVI > {{ params.T_NDVI_P25 }}。 第二個條件用來排除稻田、蔬菜等有休耕 / 翻土期的季節性作物，只留下「整年都綠」的木本植被（森林、果園、竹林、行道樹等）。
  • 10 m 解析度無法數出「棵數」，因此本站以樹冠覆蓋面積（公頃）作為「樹冠數量」的代理指標。

4. 疑似太陽能板

以台南七股漁電共生區（2024-01 影像）人工校正，太陽能板的光譜特徵很明確：近紅外（B8 ≈ 0.08）很低， 短波紅外 SWIR1（B11 ≈ 0.26）卻很高，且藍光略高於紅光。魚塭水面的 SWIR1 極低（≈ 0.04），聚落建物的 SWIR1/NIR 差異也小得多，因此可以有效區分：

NDVI < {{ params.PV_NDVI_MAX }}  且  (B11 − B8)/(B11 + B8) > {{ params.PV_SWIR_NIR_MIN }}
且  (B2 − B4)/(B2 + B4) > {{ params.PV_BLUE_RED_MIN }}  且  B8 < {{ params.PV_NIR_MAX }}  且  B11 > {{ params.PV_SWIR_MIN }}
3×3 形態學閉運算（補面板列間空隙）後，連通區塊 ≥ {{ params.PV_MIN_PIXELS }} 像元（{{ params.PV_MIN_PIXELS / 100 }} 公頃）

抽查：彰濱工業區、嘉義布袋、台南七股的大型地面 / 漁電共生案場，區塊內約 75–90% 像元被偵測到；小於 0.2 公頃的屋頂型光電與零散案場大多偵測不到，因此光電面積應視為下限。

5. 逐像元時間序列（{{ y1 }}–{{ y2 }}）

兩兩年份直接相減會被雲、物候、門檻邊緣像元放大雜訊，因此對每個 10 m 像元的逐年類別序列做判斷。 統計以 {{ y1 }} 為基準年（分析年份 {{ ana|join("、") }}）；{{ ref|join("、") }} 只有 Sentinel-2A 一顆衛星，觀測少、樹冠系統性低估， 只當參考資料顯示在各年面積與分類地圖，不參與以下判斷。

  • 光電完工年：第一個「該年為太陽能板，且下一年仍為太陽能板（或下一年無資料 / 已是最後一年）」的年份。單一年份的誤判不會被計入。 {{ y1 }} 已是太陽能板者視為「{{ y1 }} 以前已存在」，不計入新增。
  • 光電前身：看完工年之前（基準年起）的有效年份，依序判斷：
    1. 樹冠：過半數年份為樹冠（涵蓋「砍樹 → 整地裸露一兩年 → 完工」）—— 即「砍樹光電」
    2. 水體：≥ 1/3 年份為水體（魚塭、鹽田、埤塘會週期性放乾，不要求過半）—— 漁電共生、水面型光電
    3. 農地 / 低植生：低植生年數 ≥ 裸露地年數（平手算農地，因整地多半是施工的一部分）—— 農地種電
    4. 裸露地 / 建物：其餘（含長期整地、乾鹽田、工業區、屋頂）
  • 砍樹光電案場：連通的光電區塊（≥ 0.2 公頃）中，原為樹冠的面積 ≥ {{ (tree_frac * 100)|int }}%。
  • 樹冠明確消失：最近一次有效觀測為樹冠，該年轉為裸露地/建物/光電/水體，且下一年沒有恢復為樹冠。 含崩塌、農地整地、伐採、開發等所有原因；轉為「低植生」的不計（多為季節或門檻雜訊）。
  • 各年樹冠 / 光電面積：有效像元中的比例 × 縣市面積，減少各年雲遮程度不同造成的偏差。

「先砍樹、空窗、再蓋光電」路徑分析

「砍樹光電」只算完工前多數年份是樹的像元；空窗期較長時會被歸為農地或裸露地。因此另外對每個新增光電像元的完整序列分層：

  1. 多數年份是樹：即本站主要數字。
  2. 先砍樹、空窗多年再蓋：分析年份中 ≥ 2 年是樹，最後一次是樹之後到完工都不是樹；記錄空窗年數與空窗期類別。
  3. 基準年前已砍除：分析年份從未是樹，只有參考年 {{ ref|join("、") }} 是樹。
  4. 只有 1 年是樹：證據弱，多為分類雜訊。

6. 第二階段：外部圖資與驗證

  • 能源署電業級案場（取得施工許可、≥ 2 MW，108–113 年，419 案）：地號無法以開放 API 轉座標，以鄉鎮為單位比對土地面積與偵測面積。
  • 同意備案容量 / 累計裝置容量：縣市、全國尺度比對（含屋頂型，衛星看不到）。
  • 地形：Copernicus DEM 30 m，σ = 60 m 平滑後逐像元計算坡度；山坡地以法定定義「標高 ≥ 100 m 或坡度 ≥ 5%」推估， 以非六都官方山坡地範圍圖檢核（案場層級 precision 0.60、recall 0.85）。
  • 國有林事業區：林業保育署 1141 版。

詳見 驗證與圖資。

7. 已知限制

  • 2017 年只有 Sentinel-2A 為主（2B 於 2017-03 發射），可用景數較少，山區去雲後仍可能有空洞。
  • 工業區大型屋頂、電廠內設施型光電（如能源署清單中的台中龍井、高雄小港）土地面積大但面板分散，衛星偵測面積遠低於案場土地。
  • 最後一年（{{ y2 }}）完工的光電只有一年觀測，無法以隔年確認，誤判機率較高。
  • 10 m 像元對小型屋頂型光電、零星砍伐偵測力有限；深藍色金屬屋頂、部分溫室可能被誤判為太陽能板，應搭配右側正射影像目視確認。
  • 「樹冠消失」包含颱風崩塌、農地整地、伐採更新等，不全是光電所致；只有「樹冠 → 疑似太陽能板」才直接對應光電。
  • SI 門檻、NDVI 門檻為全台單一值，未針對地形陰影與不同季節做逐區校正。
